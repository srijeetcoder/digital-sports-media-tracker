# 🏆 Digital Sports Media Tracker

A premium, high-performance web application designed for athletes, scouts, and fans to monitor and manage digital sports media assets effortlessly.

![Project Status](https://img.shields.io/badge/Status-Live-emerald?style=for-the-badge)
![Next.js](https://img.shields.io/badge/Next.js-14-black?style=for-the-badge&logo=next.js)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-blue?style=for-the-badge&logo=tailwind-css)

## ✨ Features

- **State-of-the-art UI**: Experience a sleek, dark-themed interface with glassmorphism and smooth animations.
- **Real-time Tracking**: Submit and monitor media URLs with instant feedback.
- **Asset Management**: View your tracked media in a beautifully organized grid.
- **Fast & Responsive**: Built with Next.js 14 for lightning-fast performance and full responsiveness.

## 🚀 Deployment (Vercel Ready)

This project is optimized for **Vercel**. Since the backend logic is now integrated into Next.js API routes, you can deploy the entire app in one click!

### Local Setup

1. **Clone & Install:**
   ```bash
   cd frontend
   npm install
   ```

2. **Run:**
   ```bash
   npm run dev
   ```
   Navigate to [http://localhost:3000](http://localhost:3000).

---
**Note:** The separate `backend` folder is now optional and kept for reference. The live app uses `pages/api/media.js`.

## 🛠️ Technology Stack

- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Node.js, Express
- **Styling**: Modern CSS with PostCSS
